# Kebijakan Privasi TERRA WOI

Berlaku sejak: 20 Oktober 2026

TERRA WOI adalah alat bantu informasi kebencanaan. Aplikasi ini **tidak memiliki server sendiri, tidak memakai akun, dan tidak memuat iklan atau pelacak analitik**.

## Data yang disimpan di perangkat Anda

Data berikut hanya disimpan di perangkat dan tidak dikirim ke pengembang:

- lokasi terakhir yang dianalisis dan lokasi tersimpan (rumah, kantor, dll.);
- kontak keluarga, rencana darurat keluarga, dan checklist Tas Siaga;
- pilihan tema, bahasa, dan pengaturan;
- salinan data publik dan peta yang disimpan agar bisa dipakai tanpa internet.

Semua data ini terhapus bila aplikasi dicopot atau datanya dihapus lewat pengaturan Android. Aplikasi tidak membuat cadangan ke cloud.

## Data yang dikirim ke pihak ketiga

Untuk menilai bahaya di sekitar Anda, aplikasi mengirim **koordinat lokasi** (tanpa identitas Anda) langsung dari perangkat ke penyedia data publik berikut:

| Penyedia | Kegunaan |
|---|---|
| BMKG | gempa terkini, peringatan dini cuaca |
| USGS | gempa terkini |
| Open-Meteo (termasuk Copernicus CAMS & GloFAS) | cuaca, kualitas udara, debit sungai, pencarian nama tempat |
| OpenStreetMap (Overpass, Nominatim, tile peta) | titik kumpul, bangunan, sungai, nama tempat, peta |
| routing.openstreetmap.de (OSRM) | rute evakuasi |
| Badan Geologi / Geoportal ESDM | geologi, sesar, zona kerawanan |
| MAGMA Indonesia (PVMBG) | status gunung api |
| NASA FIRMS | titik panas kebakaran |
| PetaBencana.id | laporan banjir warga |
| BNPB InaRISK | titik evakuasi resmi |
| Esri (ArcGIS Online), OpenTopoMap | tile peta |
| Macrostrat, AWS Open Data (Terrarium) | data geologi & elevasi |
| GitHub | memeriksa versi aplikasi terbaru (tanpa lokasi) |

Setiap penyedia tunduk pada kebijakan privasinya sendiri. Penyedia dapat melihat alamat IP Anda seperti saat membuka situs web biasa.

## Pesan yang Anda kirim

Tombol "Saya aman", "Butuh bantuan", SOS, dan "Bagikan rencana" hanya menyiapkan pesan berisi status dan tautan lokasi. Pesan baru terkirim bila Anda memilih aplikasi tujuan (WhatsApp, SMS, dll.) dan menekan kirim di sana.

## Izin Android

| Izin | Alasan |
|---|---|
| Lokasi | menilai bahaya dan mencari tempat aman di sekitar Anda |
| Notifikasi | peringatan gempa, tsunami, banjir, dan cuaca ekstrem |
| Internet & status jaringan | mengambil data publik di atas |
| Layanan latar depan | mode siaga tinggi (opsional), memeriksa BMKG tiap menit |
| Mulai saat perangkat dinyalakan | memulihkan pemantauan setelah HP dinyalakan ulang |
| Getar | pola getar saat peringatan |

Senter pada layar SOS dinyalakan tanpa izin kamera. Aplikasi tidak memotret atau merekam.

## Anak-anak

Aplikasi ini tidak ditujukan khusus untuk anak-anak dan tidak mengumpulkan data pribadi dari siapa pun.
